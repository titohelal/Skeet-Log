SKEET LOG - how to put it on your phone

1. UPLOAD (GitHub Pages, free)
   - Sign in at github.com -> "New repository" -> name: skeet-log -> Public -> Create.
   - Click the "uploading an existing file" link (or Add file -> Upload files).
   - Drag in EVERYTHING inside this folder, including the "fonts" and "icons" folders.
     Upload the contents, not the skeet-log folder itself: index.html must sit at the top level.
   - Commit changes.
   - Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
   - Wait 1-2 minutes. Your app: https://YOUR-USERNAME.github.io/skeet-log/

2. INSTALL
   iPhone:  open the link in Safari -> Share button -> Add to Home Screen -> Add.
   Android: open the link in Chrome -> three-dot menu -> Install app.
   Open it once while online. Then turn on airplane mode and open it again to check it works offline.

3. BRING YOUR DATA OVER
   Old version (in Claude): More -> Data -> Export backup (.json)
   New app:                 More -> Data -> Import backup -> pick that file

4. KEEP IT SAFE
   Your scores live only on this phone. Deleting the icon deletes them.
   Export a backup every couple of weeks (the app reminds you after 14 days)
   and keep it in iCloud Drive or Google Drive.

5. UPDATING LATER
   Upload the new files over the old ones on GitHub (same names).
   Open the app while online. When it says "Update installed", close and reopen it.
